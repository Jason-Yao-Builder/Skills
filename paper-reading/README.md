# Paper Reading｜把论文讲透

[SKILL.md](SKILL.md)说明讲解方向：结合费曼式思维与创造者思维，既讲明白论文，也从研究者的位置理解问题、方法与证据如何形成，以及如何检验和推进研究。

## 示例

[谁先把 AI 用起来了？——A06 论文解读](examples/A06_AI_Adoption_in_America.md)是用户在多轮讨论后认可的完整示例，来自《AI Adoption in America: Who, What, and Where》。它保留了深入的方法、数据和结果解释，并以连续的问题连接全文。

借鉴的是解释的方式和深入程度，不是标题、章节数、篇幅或表格格式。不同论文有不同的核心问题，理论推导、实验证据和描述性测量应各自找到合适的讲法。

本公开副本保留论文解读正文与公开来源链接，移除了个人资料库路径和内部台账引用，不包含论文 PDF。它是表达示例，不是要求所有研究沿用的结论或数据来源。示例中的核验日期是原稿记录；本次整理未重新联网核验其中的论文与数据。
