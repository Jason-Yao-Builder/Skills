# Agent Prompt

将作者经过迭代的全局 AGENTS.md 协作约定整理为可复用 Skill。重点是先把问题讲清楚，再推演如何解决，最后落到可实现、可验证的结果。

## 使用方式

读取 [完整协作约定](references/global-instructions.md)，按本次任务应用相关部分。

- 解释问题时：使用费曼式理解与创造者式推演，建立背景、问题、朴素方案、新机制及能力边界的连贯主线。
- 研究或判断时：区分事实、来源与推断，准确引用；不把设计设想写成已知事实。
- 执行任务时：遵循现有文件、模块化、入口校验、适度验证和可独立验收的分工约定。
- 配置或迁移时：保留原有用户偏好；先核对目标 Agent 的全局配置位置、工具能力、笔记库、归档目录及运行环境。

## 全局配置与 Skill 的区别

本 Skill 在被加载时提供协作指导；把它放进技能目录不等于自动改写或永久启用全局 AGENTS.md。只有用户要求配置或迁移全局规则时，才合并到用户指定的配置文件，并保留已有规则。

参考文件里的 `~/.codex/AGENTS.md`、`~/.agents/skills/`、Obsidian 本地端口、managed/registry 目录等是可调整的环境约定。不要假定其他人的电脑具有相同路径、服务、凭据或工具。

本 Skill 不授予额外操作权限，不覆盖宿主系统要求或用户本次明确指令。涉及授权的规则沿用已有会话授权，避免重复确认。
